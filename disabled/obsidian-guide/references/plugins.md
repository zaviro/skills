# Recommended Obsidian Plugins

## Core Plugins (Built-in)

| Plugin | Purpose |
|--------|---------|
| Daily notes | Automatic daily journal |
| Templates | Note templates |
| Backlinks | See what links to current note |
| Graph view | Visual note connections |
| Quick switcher | Fast note navigation (Ctrl+O) |
| Command palette | All commands (Ctrl+P) |

## Community Plugins

### Essential
- **Dataview** - Query notes like a database
- **Templater** - Advanced templating
- **Calendar** - Calendar view for daily notes

### Organization
- **Tag Wrangler** - Rename/merge tags
- **Folder Note** - Index notes for folders
- **Recent Files** - Quick access to recent notes

### Writing
- **Natural Language Dates** - Type "tomorrow" for dates
- **Paste URL into selection** - Clean link pasting
- **Advanced Tables** - Better table editing

### Visual
- **Minimal Theme Settings** - Theme customization
- **Style Settings** - CSS customization
- **Excalidraw** - Drawings in notes

## Installing Plugins

1. Settings > Community plugins
2. Turn off "Restricted mode"
3. Browse and install

## Plugin Settings Location
```
.obsidian/plugins/plugin-name/
├── data.json      # Plugin settings
└── main.js        # Plugin code
```

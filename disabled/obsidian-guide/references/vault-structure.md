# Vault Structure Guide

## Recommended Layout

```
~/Documents/Obsidian/
├── 00-Inbox/           # Quick capture, unsorted notes
├── 01-Daily/           # Daily notes (YYYY-MM-DD.md)
├── 02-Projects/        # Active project notes
├── 03-Areas/           # Ongoing life areas (Health, Finance, Career)
├── 04-Resources/       # Reference material, learning notes
├── 05-Archive/         # Completed projects, old notes
├── Templates/          # Note templates
└── Attachments/        # Images, PDFs, files
```

## PARA Method

| Folder | Contents |
|--------|----------|
| Projects | Active, time-bound work |
| Areas | Ongoing responsibilities |
| Resources | Reference materials |
| Archive | Inactive items |

## Naming Conventions

- **Notes**: `descriptive-title.md` (kebab-case)
- **Daily**: `YYYY-MM-DD.md`
- **Projects**: `project-name/` folder with index note
- **Avoid**: Special characters, very long names

## Folder Settings

Create `.obsidian/` folder settings:
- `app.json` - Core settings
- `appearance.json` - Theme settings
- `hotkeys.json` - Keyboard shortcuts
